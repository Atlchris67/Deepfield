# Ship design, first playable slice

Typed fleets have five hulls: interceptor, torpedo boat, cruiser, bomber, and disruptor. Each clan has one saved package for each hull. Existing saves without packages load as Standard. The package applies to every ship of that hull in the clan, including ships built before the change. Enemy package choices are private.

The Ship design tab lists each hull's active package and can add a package change to the turn draft at an owned design yard. Standard uses the established counter combat. Assault adds one attack shot per four ships of that hull in a simultaneous salvo. Reinforced absorbs one salvo loss per four ships of that hull. Assault + Reinforced grants both effects. The hull counter relationships and build prices stay the same. Package changes cost 12 credits. In real-system campaigns Assault also costs two Ceryth and one Neralite; Reinforced costs two Ferrite and one Vardite; the combined package costs both material sets. Material reservations and shortages appear with other draft orders before Commit.

Only one package change per hull can be drafted each turn. The choice takes effect after that turn's battles, so it affects combat starting next turn. A package change can be removed from the draft before Commit. Changing back to Standard costs 12 credits and no materials. Classic generic-ship campaigns cannot use packages. New real campaigns offer Typed hulls and ship design as the default fleet rule, with Classic generic ships as an option. Existing campaigns keep their saved combat rules.

This slice uses clan-wide hull packages rather than individual ship variants. The saved five-count fleet representation, movement limits, fog, and existing order receipts remain compatible.
